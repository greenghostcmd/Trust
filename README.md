
# TRUST

***Trust no one.***

TRUST is a cool 2D pixl art puzzle game about exploration, observation, and figuring out what is actually going on (it's quite confusing).

Explore the levels, interact with objects, look for clues, and pay attention to things that seem out of place.

Not everything is going to be as straightforward as it looks.

## Gameplay

The gameplay is cool and kinda confusing. 

You'll need to look around, interact with things, and remember what you find. Some objects might change, disappear, or reveal something useful as you progress.

There isn't always an obvious answer, so take your time and look around.

## Controls

| Key | Action |
| --- | --- |
| `WASD` | Move |
| `E` | Interact |
| `ESC` | Pause |
| `R` | Restart |
